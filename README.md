# 課題 6-1: 他のクラスのメソッド呼び出し

### 課題の説明
コマンドライン引数（実行時引数）から2つの整数を受け取り、その「積（掛け算）」と「商（割り算）」を計算して出力するプログラムを作成しなさい。

ただし、計算を行うための`Calculator`クラスを新規作成し、その中に以下のメソッドを実装すること。また、`Prog61`クラスのmainメソッドから
それらのメソッドを呼び出すこと。


| メソッド名  | 戻り値の型    | 引数リスト        | 処理内容                      |
|----------|----------|--------------|---------------------------|
| multiply | int      | int a, int b | a x b の結果を返す              | 
| divide   | double   | int a, int b | a ÷ b の結果を返す。ただし、 b  が 0 の場合は 0 を返す | 

※ `divide` メソッドで小数まで計算する際は、型変換（キャスト）に注意すること。

積を計算します
14
商を計算します
